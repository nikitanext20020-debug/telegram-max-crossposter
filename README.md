# Кросспостинг Telegram → MAX

Сервис автоматически публикует новые посты Telegram-канала в канал MAX.
Поддерживаются:

- текст и основные стили Telegram (жирный, курсив, подчёркивание, зачёркивание, код, ссылки);
- фото, видео, GIF, аудио, голосовые сообщения и документы;
- фото- и видеоальбомы (до 12 вложений в одном сообщении MAX);
- опросы и геолокация в текстовом виде;
- единая подпись-ссылка под каждым сообщением в MAX;
- ограничение одним или несколькими исходными Telegram-каналами;
- защищённый Telegram webhook и повторная отправка, если MAX временно обрабатывает файл.

## Важно: сначала замените токены

Токены, однажды отправленные в чат или опубликованные где-либо ещё, следует
считать скомпрометированными.

1. В BotFather перевыпустите токен Telegram-бота (`/revoke`, затем `/token`).
2. В настройках бота MAX перевыпустите токен доступа.
3. Старые токены больше нигде не используйте.

Сервис читает токены только из секретных переменных окружения. В репозитории
их хранить нельзя.

## 1. Подготовка

Нужен Node.js 22 или новее.

```bash
cp .env.example .env
```

Откройте `.env` и вставьте **новые** токены. Создайте секрет webhook:

```bash
openssl rand -hex 24
```

Результат поместите в `TELEGRAM_WEBHOOK_SECRET`.

## 2. Получение ID канала MAX

1. Добавьте MAX-бота в канал.
2. Назначьте его администратором с правом публикации сообщений.
3. Выполните:

```bash
npm run discover:max
```

Скопируйте выведенную строку `MAX_CHAT_ID=...` в `.env`. Если событие уже
устарело, удалите бота из администраторов, добавьте снова и сразу повторите
команду.

## 3. Настройка подписи

В `.env`:

```dotenv
MAX_SIGNATURE_TEXT=Читать продолжение
MAX_SIGNATURE_URL=https://example.com/my-link
```

В MAX это отобразится как кликабельная подпись «Читать продолжение».
Она добавляется к каждому созданному сообщению, в том числе если длинный пост
или большой альбом пришлось разделить.

`MAX_SIGNATURE_URL` принимает только `http://` или `https://`.

## 4. Ограничение исходного Telegram-канала

Можно оставить `TELEGRAM_SOURCE_CHAT_IDS` пустым — тогда будут приниматься
посты из всех каналов, где Telegram-бот является администратором.

Безопаснее указать числовой ID нужного канала:

```dotenv
TELEGRAM_SOURCE_CHAT_IDS=-1001234567890
```

Для нескольких каналов используйте запятую. ID виден в логах Telegram webhook
после первой попытки либо его можно получить стандартными ботами определения
ID. Не передавайте таким ботам приватный контент.

## 5. Бесплатное размещение на Render

1. Загрузите этот проект в приватный репозиторий GitHub, без файла `.env`.
2. В [Render](https://dashboard.render.com/) выберите **New → Blueprint** и
   подключите репозиторий.
3. Render найдёт `render.yaml`, создаст Docker Web Service и попросит значения
   переменных с `sync: false`. Токены и `TELEGRAM_WEBHOOK_SECRET` вводите только
   в этом окне.
4. После запуска откройте выданный адрес
   `https://имя-сервиса.onrender.com/healthz`. Ответ должен быть `{"ok":true}`.

Бесплатный Render-сервис засыпает после 15 минут без входящих запросов и
просыпается примерно за минуту при новом webhook. Бесплатная квота составляет
750 часов работы в месяц; для строгого always-on без холодного старта нужен
платный инстанс или VPS.

## 6. Подключение Telegram webhook

Запишите выданный Koyeb адрес в локальный `.env`:

```dotenv
PUBLIC_URL=https://your-service.koyeb.app
```

Затем:

```bash
npm run register:webhook
npm run check:webhook
```

После этого добавьте Telegram-бота администратором исходного канала и
опубликуйте тестовый пост.

## Ограничения

- Telegram Bot API позволяет скачивать файлы размером до 20 МБ. Более крупный
  файл не будет перенесён, а Telegram повторит webhook; ошибка будет видна в
  логах Koyeb.
- Новый пост переносится автоматически. Редактирование и удаление уже
  опубликованного Telegram-поста не изменяет копию в MAX.
- MAX разрешает до 12 фото/видео в одном сообщении; большие наборы делятся.
  Документы и аудио отправляются отдельными сообщениями из-за ограничений
  сочетаний вложений MAX.
- Бесплатный хостинг не даёт жёсткой гарантии доступности. Для коммерчески
  важного канала лучше использовать минимальный платный тариф или VPS.
