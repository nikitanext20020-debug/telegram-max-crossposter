BRANCH=fix/telegram-file-too-big-loop
CHANGED_FIELD=Telegram getFile HTTP/API 400 "Bad Request: file is too big" classification

ROOT_CAUSE:
Telegram rejects getFile for Bot API files over 20 MiB before returning file_size.
downloadTelegramFile propagated that response as RemoteApiError instead of the
already-supported TelegramFileTooLargeError. crosspostMessages therefore
rejected, the webhook returned HTTP 500, and Telegram redelivered the same
update_id indefinitely.

CHANGED_BEHAVIOR:
downloadTelegramFile now translates only Telegram error code 400 containing
"file is too big" into TelegramFileTooLargeError. crosspostMessages catches it,
omits the oversized attachment, sends the text and explanatory fallback to MAX,
and resolves so the webhook can acknowledge and remember the update.
